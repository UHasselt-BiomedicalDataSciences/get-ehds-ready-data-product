health data product for secondary use under the European Health Data Space
(EHDS).

📖 **[Read the site](https://uhasselt-biomedicaldatasciences.github.io/get-ehds-ready-data-product/)**

## Quick start

[Quarto](https://quarto.org/docs/get-started/) is the only prerequisite.

```bash
quarto preview         # live-reloading local preview
quarto render          # build the site into docs/
./_scripts/ci.sh       # build, privacy and security checks — run before pushing
```

## Privacy

The published site makes **no third-party requests**: fonts are self-hosted, the
only script is first-party, and there is no analytics or tag manager. The build
fails if any externally loaded resource slips in.
